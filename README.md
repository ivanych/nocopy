# nocopy

CLI-утилита для копирования файлов из источника в целевой каталог с пропуском
файлов, которые уже существуют в целевом каталоге (определяется по md5 с учётом
всех вложенных подкаталогов). Реализована на Python 3, только stdlib без
сторонних зависимостей.

## Установка

Зависимостей нет. Достаточно запустить скрипт напрямую:

```
python3 nocopy.py ...
```

## Использование

```
python3 nocopy.py [-e] [-c] [-s] <исходный_каталог> <целевой_каталог> [<промежуточный_каталог>]
```

### Аргументы

| Аргумент | Описание |
|----------|----------|
| `исходный_каталог` (обязательный) | Откуда копировать. |
| `целевой_каталог` (обязательный) | Каталог, в котором ищутся дубликаты. |
| `промежуточный_каталог` (необязательный) | Если указан, файлы копируются в него, а не в целевой. Поиск дублей всё равно идёт по целевому каталогу. |

### Опции

| Опция | Описание |
|-------|----------|
| `-e`, `--exec` | Выполнить фактическое копирование. Без неё — только проверка и отчёт. |
| `-c`, `--copy` | Показывать в отчёте только файлы, которые будут скопированы. |
| `-s`, `--skip` | Показывать в отчёте только файлы, которые уже есть (не копируются). |
| `-i`, `--save-index` | Использовать готовый индексный файл `.<target>.nocopy` из текущего каталога (не создавая его); если файла нет — выводится ошибка. |
| `-I`, `--rebuild-index` | Пересоздать файл индекса, даже если он уже существует. `-i` и `-I` взаимоисключающие. |

`-c` и `-s` независимы: вместе дают все файлы. Без `-c` и без `-s` таблица
отчёта не выводится.

### Примеры

Проверка (без копирования), показать только копируемые файлы:

```
python3 nocopy.py -c ~/photo ~/backup
```

Выполнить копирование:

```
python3 nocopy.py -e ~/photo ~/backup
```

Копировать в промежуточный каталог, отчёт только по уже существующим:

```
python3 nocopy.py -e -s ~/photo ~/backup ~/staging
```

## Логика работы

1. **Сканирование целевого каталога**: рекурсивный обход всех файлов. Для
   каждого файла берётся размер, вычисляется md5. Строится индекс
   `размер → md5 → пути`. Показывается прогресс-бар.
2. **Поиск дублей в источнике**: файлы источника обрабатываются параллельно.
   Для каждого файла:
   - Сначала сверяется размер (быстрая отсечка, без чтения содержимого).
   - md5 вычисляется только если в целевом есть файлы такого же размера.
   - Если найден файл с тем же `(размер, md5)` в целевом — файл считается
     дубликатом (`SKIP`), не копируется.
   - Иначе — будет скопирован (`COPY`).
3. **Копирование** (при `-e`): файлы копируются в целевой (или промежуточный)
   каталог с сохранением относительной структуры. Если по пути уже есть файл с
   другим содержимым — создаётся уникальное имя с суффиксом `_1`, `_2`, ...
   (например `file_1.txt`). При конфликте имён в промежуточном каталоге
   существующий файл заменяется новым.

## Особенности

- Дубликат определяется по `(размер, md5)`, независимо от имени файла.
- Симлинки на каталоги обходятся и в целевом, и в источнике; рекурсивные
  симлинки отбрасываются, чтобы избежать зацикливания.
- Цвет выводится только в терминал; при редиректе в файл/пайп ANSI-коды не
  выводятся.
- Индекс целевого каталога можно сохранять (`-I`) и переиспользовать (`-i`)
  между запусками.

## Отчёт

В конце выводится сводка:

```
Всего файлов в источнике : N (размер)
Будет скопировано (COPY) : N (размер)
Уже есть в целевом (SKIP): N (размер)
Скопировано: N
Ошибок: N
```

и `Время работы: <всего> (индекс: <время>, поиск дублей: <время>)`.
